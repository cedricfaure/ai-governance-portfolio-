# Writing

Articles and essays on AI governance in practice, with a GCC lens.

## Naming convention

Files are named `YYYY-MM-slug.md`, and live in this folder once published
(drafts live in `writing/drafts/`).

Each article carries YAML front matter:

```yaml
---
title: [TODO]
date: [TODO]
summary: [TODO]
tags: []
status: draft            # draft | published
---
```
