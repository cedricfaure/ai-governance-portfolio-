# Contributing

This is a personal portfolio repository, not a community project but
corrections are genuinely welcome, especially where regulatory or technical
accuracy is concerned.

- **Issues**: if you spot an error, an outdated reference, or a broken link,
  please raise an issue. Corrections to regulatory interpretation are
  particularly appreciated.
- **Pull requests**: considered on a case-by-case basis. Small, well-scoped
  fixes (typos, broken links, factual corrections) are easiest to review and
  accept. Larger changes are less likely to be merged, as this repository
  reflects one person's work and views.
- **Contact**: the best way to reach the author is via
  [LinkedIn](https://www.linkedin.com/in/cedric).

## GitHub Pages

This repository is configured to publish `docs/` via GitHub Pages, but Pages
is not yet enabled. Once there is content worth publishing, enable it from
the repository **Settings → Pages**, with the source set to the `main`
branch and the `/docs` folder.
